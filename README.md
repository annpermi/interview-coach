# Interview Coach

A private interview prep workspace for practicing mock questions, shaping stronger answers, saving notes, and exporting sessions.

## Features

- Structured answer planning
- STAR story builder
- Risk and follow-up review
- Practice question bank
- Local notes and practice log
- Session export

## Run locally

Open `index.html` in a browser.

## Deploy

This is a static app and can be deployed directly on Vercel.
