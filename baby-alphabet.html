Baby Alphabet

A tiny terminal game I made so my baby can press keys, fill the screen with color, and start connecting letters with animals.

Made for curious little hands

Every letter key becomes a full-screen visual moment instead of random typing in a shell.

Letters, animals, and colors

The screen shows a giant letter, a giant animal word, a matching sentence, and a same-letter color.

Simple parent controls

It runs locally, needs no install beyond the script, and exits with a parent key sequence or by closing Terminal.

Why I Built It

Sometimes my baby is nearby while I am at the computer, and of course the keyboard is fascinating. I wanted a safe, playful thing to run when he reaches for the keys: no apps opening, no files changing, just a bright alphabet screen responding to him.

How It Works

Baby Alphabet is a single `zsh` script. It opens a full-screen terminal view, listens for `A-Z`, and redraws the screen with a large block letter, a large animal word, a color that starts with the same letter, and a small animal icon.

cd ~/Desktop/toddler_alphabet_game
/bin/zsh play.zsh

What I Learned

A terminal can be surprisingly expressive, but it has limits. Emoji cannot scale like text, and a shell script cannot fully lock macOS. The final version leans into what the terminal is good at: huge block letters, strong colors, and a simple interaction model that is hard for a baby to break.
